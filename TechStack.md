# Project Tech Stack

## Project Scope
This is a data analytics project focused on hospital patient readmission analysis and risk monitoring.

- Primary tools: Microsoft Excel and Microsoft Power BI
- No Python
- No machine learning
- No SQL
- No external programming or code automation

## Core Tools
### Microsoft Excel
- Store raw data as structured tables
- Perform initial data entry and staging
- Use Excel formulas for basic validation
- Maintain master data lists and reference tables

### Microsoft Power BI
- Connect directly to Excel workbooks using Power BI Desktop
- Use Power Query to import and transform data from Excel
- Build data models with relationships and lookup tables
- Create measures and calculated fields using DAX
- Design interactive dashboards and reports

## Implementation Approach
- Keep data in Excel-friendly tabular format
- Avoid any database or SQL usage
- Avoid Python, machine learning, and code-based automation
- Use Power BI for analytics and visualization only
- Use Excel for raw data collection, cleaning, and simple calculations

## Why this stack
- Aligns with the project goal of a business intelligence solution
- Keeps the workflow accessible to business and clinical users
- Removes complexity from programming and predictive modeling
- Supports a clean handoff between data preparation and dashboarding
